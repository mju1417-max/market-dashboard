## 검증 규칙 (요약)

- **S3 (한국·미국)**: 60분 +3% 이상 → 10분 눌림 -0.5% 이하 → 2분 반등 +0.6% 이상, 진입 시 2분 거래량이 60분 평균의 2.5배 이상
- **S1 (업비트)**: 5분 거래량이 60분 평균의 3배 이상 → 5분 +0.5% 이상 → 최근 5봉 중 양봉 3개 이상
- 체결은 신호 확정 이후 첫 봉의 시가, 보유 30분, -3% 손절 / +5% 익절, 수수료·슬리피지·거래세 반영
- 백필 없음: 전진검증 시작 이후 관측된 봉만 신호 대상으로 삼아 과거 데이터로 성과를 만들지 않습니다.
